# Project 05: Vehicle License Plate Recognition using OpenCV and OCR

## Deskripsi Proyek
Pengembangan sistem parkir otomatis dengan deteksi dan pengenalan plat nomor kendaraan menggunakan OpenCV (image processing) dan EasyOCR (text extraction). Sistem ini diuji pada 15 gambar real dengan akurasi 83.85%.

## Teknologi yang Digunakan
| Teknologi | Keterangan |
|-----------|------------|
| Python | Bahasa pemrograman utama |
| OpenCV | Image processing dan deteksi plat |
| EasyOCR | Optical Character Recognition |
| NumPy | Operasi array dan matriks |
| Matplotlib | Visualisasi hasil |

## Akurasi
**83.85%** (testing pada 15 gambar real)
