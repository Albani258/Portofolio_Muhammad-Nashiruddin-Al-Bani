# Project 02: Household and Item Request Management System (Laravel)

## Deskripsi
Sistem informasi manajemen inventaris dan pengajuan barang untuk Divisi Rumah Tangga BPSDM IMIPAS Kementerian Imigrasi dan Pemasyarakatan RI.

## Teknologi yang Digunakan
- **Framework**: Laravel (PHP)
- **Database**: MariaDB / MySQL
- **Web Server**: Nginx
- **Runtime**: PHP-FPM

## Fitur Utama
- Manajemen inventaris barang
- Pengajuan permintaan barang
- Proses pengadaan
- Role-Based Access Control (RBAC)
- Admin dan User management
