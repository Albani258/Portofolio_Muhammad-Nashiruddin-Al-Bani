# 📈 Project 08: Risk Modeling - Optimal Portfolio Analysis (Markowitz Model)

## 📋 Project Overview
Optimal portfolio allocation analysis in the Indonesian energy sector using the **Markowitz Mean-Variance Model**.

## 📊 Stocks Analyzed
| Code | Company | Sector | Optimal Weight |
|------|---------|--------|----------------|
| AKRA | PT AKR Corporation Tbk | Energy distribution | **56.1%** |
| ADMR | PT Adaro Minerals Indonesia Tbk | Coal | **23.3%** |
| MEDC | PT Medco Energi Internasional Tbk | Oil & gas | **20.6%** |

## 📈 Portfolio Performance
| Metric | Value |
|--------|-------|
| Expected Return | 0.00081 |
| Portfolio Risk (Std Dev) | 0.0428 |

## 📅 Data Period
April 26, 2023 – April 23, 2024 (daily closing prices)

## 💡 Conclusion
The results show a well-diversified portfolio with stable profit potential and moderate risk.
