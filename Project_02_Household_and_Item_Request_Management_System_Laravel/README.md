# 🏠 Project 02: Household & Item Request Management System

## 📋 Project Overview
A web-based inventory and item request management system for the **Household Division of BPSDM IMIPAS**, Ministry of Immigration and Corrections of the Republic of Indonesia.

## 🚀 Technologies Used
| Technology | Description |
|------------|-------------|
| Laravel | PHP Framework |
| PHP | Backend |
| MySQL/MariaDB | Database |
| Nginx | Web Server |
| Bootstrap | Frontend |

## ✨ Key Features
- Inventory management
- Item request submission
- Procurement process
- Role-Based Access Control (RBAC)

- Team Leader
- Development and implementation coordination
