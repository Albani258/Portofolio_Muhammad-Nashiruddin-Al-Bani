# 🏠 Project 02: Household & Item Request Management System

## 📋 Ringkasan Proyek
Sistem informasi manajemen inventaris dan pengajuan barang berbasis web untuk **Divisi Rumah Tangga BPSDM IMIPAS** Kementerian Imigrasi dan Pemasyarakatan RI.

## 🚀 Teknologi yang Digunakan
- Laravel (PHP Framework)
- PHP (Backend)
- MySQL/MariaDB (Database)
- Nginx (Web Server)
- Bootstrap (Frontend)

## ✨ Fitur Utama
- Manajemen inventaris barang
- Pengajuan permintaan barang
- Proses pengadaan
- Role-Based Access Control (RBAC)
- Admin dan User management

## 👨‍💻 Peran Saya
- Team Leader
- Koordinasi pengembangan dan implementasi sistem

## 🏗️ Arsitektur
- Linux server deployment
- Firewall configuration
- Siap integrasi domain official
