# 💊 Project 03: Drug Needs Analysis with K-Means Clustering

## 📋 Project Overview
Analysis and clustering of drug needs data using the **K-Means** method to support decision-making at the **Yogyakarta City Health Service**.

## 🚀 Technologies Used
| Technology | Description |
|------------|-------------|
| R | Programming language |
| RStudio | IDE |
| ggplot2 | Data visualization |
| K-Means | Clustering method |

## 📊 Analysis Steps
1. Data preparation
2. Descriptive analysis
3. Determine optimal cluster count (Elbow Method)
4. Object clustering
5. Model evaluation

## 📁 Folder Structure
| Folder | Contents |
|--------|----------|
| `01_Dokumentasi` | Analysis reports, presentations |
| `02_Code` | R scripts for clustering |
| `03_Data` | Drug needs dataset |
| `04_Output` | Cluster graphs and visualizations |
