# Project 03: Drug Needs Analysis with K-Means Clustering (R)

## Deskripsi
Analisis dan clustering data kebutuhan obat menggunakan metode K-Means untuk mendukung pengambilan keputusan di Dinas Kesehatan Kota Yogyakarta.

## Teknologi yang Digunakan
- **Bahasa Pemrograman**: R
- **IDE**: RStudio
- **Visualisasi**: ggplot2, base R plotting
- **Metode**: K-Means Clustering, Elbow Method

## Tahapan Analisis
1. Data preparation
2. Descriptive analysis
3. Menentukan jumlah cluster optimal (Elbow Method)
4. Analisis initial cluster centroid
5. Object clustering
6. Evaluasi model

## Output
- Visualisasi cluster
- Tabel ringkasan setiap cluster
