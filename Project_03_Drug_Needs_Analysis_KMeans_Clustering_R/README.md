# 💊 Project 03: Drug Needs Analysis with K-Means Clustering

## 📋 Ringkasan Proyek
Analisis dan clustering data kebutuhan obat menggunakan metode **K-Means** untuk mendukung pengambilan keputusan di **Dinas Kesehatan Kota Yogyakarta**.

## 🚀 Teknologi yang Digunakan
- R
- RStudio
- ggplot2
- K-Means Clustering

## 📊 Tahapan Analisis
1. Data preparation
2. Descriptive analysis
3. Menentukan jumlah cluster optimal (Elbow Method)
4. Analisis initial cluster centroid
5. Object clustering
6. Evaluasi model

## 📈 Output
- Visualisasi cluster
- Tabel ringkasan setiap cluster

## 📁 Struktur Folder
| Folder | Isi |
|--------|-----|
| `01_Dokumentasi` | Laporan analisis, presentasi |
| `02_Code` | Script R untuk clustering |
| `03_Data` | Dataset kebutuhan obat |
| `04_Output` | Grafik dan visualisasi cluster |
