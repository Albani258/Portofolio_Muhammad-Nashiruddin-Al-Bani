# Project 07: Glass Classification with Learning Vector Quantization (Python)

## Deskripsi
Klasifikasi jenis kaca berdasarkan indeks bias dan komposisi kimia menggunakan Learning Vector Quantization (LVQ) untuk mendukung investigasi forensik.

## Teknologi yang Digunakan
- **Bahasa Pemrograman**: Python
- **Library**: NumPy, Pandas, Scikit-learn, Matplotlib
- **Dataset**: UCI Glass Dataset (214 samples)
- **Metode**: Learning Vector Quantization (LVQ)

## Fitur Dataset (10 fitur numerik)
- Refractive index
- Na, Mg, Al, Si, K, Ca, Ba, Fe (komposisi kimia)

## Target (7 kategori)
- Building windows
- Vehicle windows
- Containers
- Tableware
- Headlights
- dll.

## Hasil Evaluasi
- **Validasi**: 5-Fold Cross Validation
- **Akurasi rata-rata**: 70%
- **Akurasi tertinggi**: 78.57%

## Parameter LVQ
- Learning rate: 0.1
- Epoch: 25
- Representative subsets: 50
