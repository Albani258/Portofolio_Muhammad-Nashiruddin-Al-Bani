# Project 09: Stock Portfolio App with R Shiny

## Ringkasan Proyek
Aplikasi web portofolio saham interaktif dengan R Shiny.

## Teknologi yang Digunakan

- R Shiny

- Menghitung rasio keuangan
- Optimasi portofolio
